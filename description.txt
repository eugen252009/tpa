Automation tool for Debian packages and repository construction
 tpa creates Debian package trees and derives verified APT repositories from
 actual .deb artifacts. Package metadata can be supplied through command-line
 flags or JSON configuration.
 .
 Repository metadata and hashes are derived from package bytes. TPA can sign
 Release metadata and atomically replace a verified repository tree on Linux.
 Detailed usage is available in the tpa(1) manual page.
