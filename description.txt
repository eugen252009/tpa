Description: Automation tool for Debian packages and repository bundling
 tpa is a minimalist package builder and repository bundler for .deb archives.
 It serves as a tool for the automated creation of packages from JSON 
 blueprints or via direct parameter passing using command-line flags.
 .
 As a standalone tool, tpa decouples packaging from system structure and 
 enables the efficient orchestration of software stacks. It also automates 
 the creation of apt-compatible repositories, including indexing. Detailed 
 documentation can be found in the corresponding manpage (man tpa).
